# SIM Бонус — компьютер ва Android телефонга илова қилиб ўрнатиш

Бу версия PWA форматда тайёрланган. Дастур Railway/онлайн серверда ишлайди, лекин компьютер ва Android телефонда оддий сайтга ўхшамай, алоҳида илова иконкаси билан очилади.

## 1. Аввал онлайн серверга чиқаринг

GitHub репозиторийга шу папка ичидаги файлларни юкланг ва Railway орқали deploy қилинг. PostgreSQL қўшинг. Variables ичида DATABASE_URL ва SECRET_KEY бўлсин.

## 2. Android телефонга ўрнатиш

1. Телефонда Chrome браузерни очинг.
2. Railway берган HTTPS ссылкага киринг.
3. Логин/парол билан киринг.
4. Экранда “Телефон/компьютерга илова қилиб ўрнатиш” тугмаси чиқса, шуни босинг.
5. Агар тугма чиқмаса: Chrome менюси ⋮ → “Add to Home screen” ёки “Install app” ни босинг.
6. Телефон экранида “SIM Бонус” иконкаси пайдо бўлади.

## 3. Windows компьютерга ўрнатиш

### Chrome орқали
1. Chrome браузерда Railway HTTPS ссылкани очинг.
2. Логин/парол билан киринг.
3. Адрес қаторининг ўнг томонидаги Install белгисини босинг ёки дастурдаги “Илова сифатида ўрнатиш” тугмасини босинг.
4. “Install / Ўрнатиш” ни тасдиқланг.
5. Windows Start меню ва Desktop орқали очиладиган “SIM Бонус” иловаси пайдо бўлади.

### Edge орқали
1. Edge браузерда Railway HTTPS ссылкани очинг.
2. Меню ⋯ → Apps → Install this site as an app.
3. Номини “SIM Бонус” қилиб сақланг.

## 4. Эслатма

- Маълумотлар телефон ёки компьютерда эмас, онлайн PostgreSQL базада сақланади.
- Телефон алмашса ҳам, ссылка орқали кирсангиз маълумотлар сақланиб туради.
- Интернет бўлмаса дастур маълумот кирита олмайди, чунки база онлайнда.
- Биринчи кириш: admin / admin123. Киргандан кейин паролни алмаштиринг.
